# Checklist manual de PWA

Use a build de produção publicado em `https://vibecoded-org.github.io/zovidoo/` para esta validação final antes de cada release importante.

| Ambiente | Verificar |
| --- | --- |
| Chrome Android | Instalação, abertura offline após a primeira visita, navegação por tabs, áudio e aviso de atualização. |
| Safari iOS/iPadOS | **Adicionar à Tela de Início**, abertura standalone, safe areas, tabs, áudio após toque e funcionamento offline. |
| Navegador desktop | Instalação quando disponível, deep link em `/zovidoo/tabs/home`, troca de idioma, atualização e restauração de backup. |

Em todos os ambientes, confirme que o áudio para imediatamente ao responder ou sair do exercício e que o lembrete informa corretamente que só pode disparar enquanto o app estiver aberto.
